İzmir API Servislerini Canlı Deneyin

Aşağıdaki servislere tıklayarak TypeScript kod şablonlarını, canlı API yanıtlarını ve GeoJSON formatındaki çıktıları anında inceleyebilirsiniz.

Belediye Servisleri
Mimari Güç

Üretim Ortamları İçin Tasarlandı

Oran sınırlamaları, ağ zaman aşımları ve heterojen koordinat sistemleri gibi belediye açık veri altyapılarının tüm zorluklarını çözen yerleşik katmanlar.

Configurable In-Memory Cache

Belediye sunucularına gereksiz ağ istekleri atılmasını engelleyen dahili TTL önbellek. Özel süreler ve FIFO tahliye ile bellek sınırlarını korur.

const api = new IzmirAPI({ cache: true });

Request Retry ile Jitter

Geçici 5xx hatalarında ve ağ kesintilerinde rastgele sapmalı (jitter) üstel geri çekilme. Sunucularda yığılma yaratmadan istekleri güvenle tekrarlar.

retry: { retries: 3, baseDelayMs: 300, jitter: true }

CKAN Akıcı Sorgu Motoru

Datastore kaynaklarında filtreleme, metin araması, sıralama ve sayfalama işlemlerini zincirleme (fluent) metotlarla derleyip çalıştırır.

api.ckan.query(id).where("ILCE", "KONAK").page(1, 25);

GeoJSON Normalizasyonu

Farklı birimlerin kullandığı CBS (BOYLAM/ENLEM) ve Yazılım Şube (LokasyonX/Y) koordinatlarını doğrudan standart RFC 7946 FeatureCollection nesnesine çevirir.

const geojson = toGeoJSON(belediyeVerisi);
