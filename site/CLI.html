Terminal CLI Kılavuzu

izmir-open-data-js, belediye açık veri portallarını terminal üzerinden sorgulamak, filtrelemek ve ASCII tabloları halinde görselleştirmek için izmir-cli komut satırı aracını sunar.

Kurulum ve Paket Yöneticileri

1. Homebrew ile Kurulum (macOS / Linux)

Official Homebrew Tap üzerinden kalıcı global CLI kurulumu:

bash
# Tap ekleyip kurma brew tap AtaCanYmc/tap brew install izmir-cli # Veya doğrudan tek komutla: brew install AtaCanYmc/tap/izmir-cli

Kurulum tamamlandığında hem izmir-cli hem de izmir komutu terminalinizde hazır hale gelir.

2. npm / npx ile Çalıştırma

bash
# Global npm kurulumu npm install -g izmir-open-data-js # npx ile anında çalıştırma (kurulum gerektirmez): npx izmir-cli get cbs/bisimistasyon

Komut Referansı

Komut Parametreler Açıklama
get <dataset_id> Belirtilen veri seti kimliğine ait kayıtları çeker ve terminal tablosunda listeler.
search <query> [-l limit] Portaldaki 260+ veri setini arar ve kaynak sayılarıyla birlikte listeler.
datastore <resource_id> [-l limit] [-q query] Herhangi bir CKAN Datastore UUID'sinden canlı kayıtları çeker ve tablolar.
--help - Komut satırı kullanım kılavuzunu ve seçenekleri görüntüler.
--version - Yüklü paket sürümünü görüntüler.

Detaylı Kullanım Senaryoları & Örnekler

1. BİSİM Akıllı Bisiklet İstasyonları

İzmir genelindeki tüm BİSİM istasyonlarının koordinat ve kapasite bilgilerini çeker:

bash
izmir get cbs/bisimistasyon

2. Canlı Otopark Doluluk Verileri

İZELMAN otoparklarının anlık boş kapasiteleri ve toplam kontenjanları:

bash
izmir get otopark/otoparklar

3. CKAN Veri Seti Arama (Package Search)

Portaldaki 260+ veri seti arasında anahtar kelime ile arama:

bash
# İtfaiye ile ilgili ilk 5 veri setini listele izmir search itfaiye -l 5 # Tuvalet veri setlerini ara izmir search tuvalet

4. Canlı Datastore Sorgulama (Resource UUID)

Belirli bir CKAN tablosundan canlı kayıtları filtreleyip tablolar:

bash
izmir datastore d87de3c1-9bc0-4a8c-842a-90cd2a30d03a -l 10

Boru Hatları & Kabuk Entegrasyonu (Pipelines)

izmir-cli komutları Unix felsefesine uygun olarak tasarlanmıştır. Çıktıları grep, fzf, awk veya crontab süreçlerine bağlayabilirsiniz.

Boru Hattı Örneği
# Nöbetçi eczaneler arasından sadece Konak ilçesini filtreleme izmir get nobetcieczaneler | grep -i "Konak" # Günlük otopark durumunu bir metin dosyasına arşivleme (Cronjob) 0 * * * * izmir get otopark/otoparklar >> /var/log/izmir_otopark.log
