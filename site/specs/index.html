Resmi API Şartnameleri Arşivi

İzmir Büyükşehir Belediyesi Bilgi İşlem Dairesi Başkanlığı ve bağlı iştirakleri (İZBAN, İZSU, İzmir Metro A.Ş.) resmi web servis şartnameleri, veri modelleri ve entegrasyon kuralları.

Ortak Teknik Standartlar

  • 1. İletişim Protokolü: RESTful HTTP GET.
  • 2. Yetkilendirme: Açık Veri Portalı servisleri anonim erişime açıktır.
  • 3. Veri Formatı: Tüm uç noktalar application/json veya CSV üretir.
  • 4. Koordinat Referans Sistemi: Tüm coğrafi konum verileri (enlem/boylam) WGS84 (EPSG:4326) projeksiyonundadır.
  • 5. Kentsel POI Şeması: CBS katmanları standart DefaultOnemliYer şemasına (ADI, ILCE, MAHALLE, YOL, KAPINO, ENLEM, BOYLAM) uyar.
