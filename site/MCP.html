Model Context Protocol (MCP) Sunucusu

izmir-open-data-js, @modelcontextprotocol/sdk altyapısı üzerine inşa edilmiş tam uyumlu bir MCP sunucusu içerir. Claude Desktop, Cursor veya yerel AI ajanlarının İzmir Açık Veri API'lerini doğrudan çalıştırmasını sağlar.

Sunucuyu Başlatma

MCP sunucusu standart girdi ve çıktı (stdio) üzerinden çalışır:

bash
# npx ile anında çalıştırma (Önerilen) npx -y izmir-open-data-js # Global paket kurulu ise: izmir-mcp

İstemci Entegrasyonları & Yapılandırma

1. Claude Desktop Entegrasyonu

~/Library/Application Support/Claude/claude_desktop_config.json (macOS) veya %APPDATA%\Claude\claude_desktop_config.json (Windows) dosyasına aşağıdaki sunucu tanımını ekleyin:

claude_desktop_config.json
{ "mcpServers": { "izmir-open-data": { "command": "npx", "args": ["-y", "izmir-open-data-js"] } } }

2. Cursor IDE Entegrasyonu

Proje kök dizinindeki .cursor/mcp.json dosyasında MCP sunucusunu tanımlayın:

.cursor/mcp.json
{ "mcpServers": { "izmir-api": { "command": "npx", "args": ["-y", "izmir-open-data-js"] } } }

Sağlanan Araçlar (Tools Reference)

1. list_endpoints Discovery Tool

İstemcideki tüm servis ad alanlarını ve bunlara bağlı çağrılabilir metotları dinamik olarak listeler. Yapay zeka modeli önce bu aracı çağırarak hangi belediye servislerinin mevcut olduğunu keşfeder.

Örnek Dizi Yanıtı
[ "bisim.getIstasyonList", "eczaneler.getNobetciList", "eshot.getHatlar", "eshot.getYakinDurakList", "izsu.getBarajDolulukOranlari", "otopark.getList", "ckan.searchPackages" ]
2. call_endpoint Execution Tool

Keşfedilen belirli bir belediye API metodunu parametreleriyle birlikte yürütür ve JSON yanıtını model bağlamına döndürür.

Alan Adı Tip Zorunlu Açıklama
namespace string Evet Servis grubu adı (ör: eshot, eczaneler, izsu, bisim).
endpoint_name string Evet Çağrılacak metodun adı (ör: getNobetciList, getYakinDurakList).
args array Hayır Metoda aktarılacak sıralı parametre listesi (ör: koordinatlar, hat no, tarih).
Örnek Parametre Çağrısı
{ "namespace": "eshot", "endpoint_name": "getYakinDurakList", "args": [38.4192, 27.1287] }

Örnek Yapay Zeka Ajanı Diyalogları

Soru: "Şu an Konak'ta açık olan nöbetçi eczaneler nerede?"

Ajan otomatik olarak call_endpoint({ namespace: "eczaneler", endpoint_name: "getNobetciList" }) metodunu tetikler. Gelen listeden Konak bölgesindeki eczanelerin telefon, harita koordinatları ve tarif bilgilerini özetleyerek kullanıcıya sunar.

Soru: "İzmir barajlarının güncel doluluk durumu nedir?"

Ajan call_endpoint({ namespace: "izsu", endpoint_name: "getBarajDolulukOranlari" }) aracını çağırır. Tahtalı, Balçova, Gördes ve Ürkmez barajlarının su hacimlerini ve yıllık doluluk oranlarını karşılaştırmalı olarak analiz eder.
