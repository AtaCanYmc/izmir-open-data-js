# Security Policy

## Supported Versions

Only the latest major release of `izmir-open-data-js` receives active security updates and vulnerability patches.

| Version | Supported | Notes |
| --- | --- | --- |
| 2.x | Yes | Current active production branch. |
| 1.x | No | Deprecated. Please upgrade to version 2.x. |
| < 1.0.0 | No | End of life. |

---

## Reporting a Vulnerability

We take the security of `izmir-open-data-js` seriously. If you discover a security vulnerability, do not open a public issue.

### Preferred Disclosure Method

Please report security issues through [GitHub Private Security Advisories](https://github.com/AtaCanYmc/izmir-open-data-js/security/advisories/new).

### Direct Email Contact

Alternatively, email vulnerability reports directly to the maintainer:

- **Contact**: `atacanymc@gmail.com`
- **Subject Line**: `[SECURITY] izmir-open-data-js Vulnerability Report`

Include the following details in your report:
1. Vulnerability description and potential impact.
2. Step-by-step reproduction instructions or proof-of-concept code.
3. Affected versions and runtime environment (Node.js version, OS).
4. Proposed mitigation or patch if available.

---

## Response Timeline and SLA

- **Initial Response**: Within 48 hours of report receipt.
- **Triage and Confirmation**: Within 5 business days.
- **Fix and Release**: Critical patches are prioritized and released within 14 days of confirmation.

We ask that you maintain responsible disclosure and refrain from publicly discussing or releasing exploit details until a security release is published.
